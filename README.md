# 🎉 Birthday Cards Collection

Bu repo, HTML, CSS ve JavaScript kullanılarak geliştirilmiş **iki farklı interaktif doğum günü kartı projesini** içerir.
Her proje, animasyonlar ve etkileşimli efektlerle kullanıcıya eğlenceli bir kutlama deneyimi sunar 🎂✨

---

## 🃏 Projeler

### 🎉 Card 1 – Interactive Birthday Card

* 🎈 Balon animasyonları
* 🎊 Konfeti efekti
* 🔄 3D kart çevirme (flip)
* 📱 Mobil uyumlu tasarım
* 👆 Tıklama ile etkileşim

---

### 🎂 Card 2 – Musical Birthday Card

* 🎵 Web Audio API ile melodi
* 🔊 Müzik aç/kapat kontrolü
* 🎊 Konfeti yağmuru
* 🎈 Animasyonlu balonlar
* ✨ Dinamik doğum günü sahnesi

---

## ⚙️ Kullanılan Teknolojiler

* HTML5
* CSS3 (Animasyon + 3D transform)
* Vanilla JavaScript
* Web Audio API

---

## 🎯 Amaç

Bu proje seti:

* CSS animasyonlarını öğrenmek
* Web Audio API kullanımı
* Etkileşimli UI tasarımı geliştirmek
* DOM event yönetimini güçlendirmek

için hazırlanmıştır.
